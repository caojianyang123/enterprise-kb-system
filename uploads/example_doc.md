# 企业私有知识库问答系统使用指南

## 功能介绍

本系统基于RAG（检索增强生成）技术，为企业提供智能问答服务。

### 核心功能

1. **文档管理**：支持上传PDF、Word、Markdown、TXT格式文档
2. **智能问答**：基于上传文档进行语义检索和问答
3. **对话历史**：记录用户对话记录，支持上下文理解

## 使用步骤

### 第一步：上传文档

在"文档管理"标签页，点击"上传文档"按钮，选择要上传的文件。

### 第二步：开始问答

在"问答对话"标签页，输入您的问题，系统会从知识库中检索相关内容并生成回答。

## 技术架构

### 系统组成

- **前端**：Streamlit Web界面
- **文档处理**：PyPDF2、python-docx、markdown库
- **向量存储**：ChromaDB
- **大语言模型**：阿里云百炼 Qwen3.7-plus

### 工作流程

1. 文档上传 → 文本提取 → 切分片段 → 生成向量 → 存入向量库
2. 用户提问 → 语义检索 → 上下文构建 → LLM生成回答

## 配置说明

### 环境变量

- **DASHSCOPE_API_KEY**：阿里云百炼API密钥
- **LLM_MODEL**：模型名称，默认qwen3.7-plus

### 参数配置

- **CHUNK_SIZE**：文本切分大小，默认500字符
- **CHUNK_OVERLAP**：切分重叠大小，默认50字符
- **TOP_K**：检索返回数量，默认3

## 常见问题

### Q1：如何上传文档？

A：在"文档管理"标签页，点击"上传文档"按钮，支持PDF、Word、Markdown、TXT格式。

### Q2：为什么检索不到内容？

A：请确保已上传相关文档，且问题与文档内容相关。

### Q3：如何清空对话？

A：点击"清空对话"按钮，系统会重置当前会话。

## 注意事项

1. 文档大小限制为50MB
2. 支持多用户同时使用
3. 对话历史会自动保存
